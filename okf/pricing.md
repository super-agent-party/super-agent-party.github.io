# Pricing — Super Agent Party

Super Agent Party is free and open source under AGPL-3.0.

## Free (Community)
- **Price**: $0
- Self-hosted; bring your own LLM API keys (OpenAI, Anthropic, Google, etc.)
- All core features included
- Community support via GitHub Issues and Discord

## Enterprise
- Custom pricing for dedicated support, SLA, and custom integrations
- Contact via GitHub or Discord
