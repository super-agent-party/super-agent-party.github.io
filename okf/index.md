# Super Agent Party

Super Agent Party (SAP) is an all-in-one open-source AI companion platform. It integrates AI desktop companions, virtual streamers, IM bots, and smart home control into a single extensible framework.

## Core Features

1. **VRM Desktop Companion** — Custom 3D/2D models with 24/7 desktop companionship
2. **Omnipotent Task Center** — AI agents execute tasks with automated PC control
3. **Native PC Control** — Desktop vision + mouse/keyboard/terminal toolchain
4. **Multi-character Chat** — SillyTavern card support with long-term memory
5. **IM Bot Matrix** — Deploy to Discord, Telegram, Slack, WeChat, QQ, Lark, DingTalk
6. **Virtual Streamer System** — AI VTuber for Bilibili, YouTube, Twitch
7. **AI Browser** — Autonomous web navigation and information gathering
8. **Infinite Ecosystem** — Plugin system with one-click install
9. **Developer Friendly** — OpenAI-compatible API and MCP protocol
