隐私政策

最后更新：2026年6月19日

1. 引言

Super Agent Party（以下简称"我们"）运营网站 www.agentparty.top（以下简称"网站"）。我们致力于保护您的隐私并确保数据处理的透明度。本隐私政策说明了我们收集哪些信息、如何使用这些信息，以及您在适用的数据保护法律（包括欧盟《通用数据保护条例》GDPR）下的权利。

2. 数据控制者

本网站的数据控制者为 Super Agent Party 项目，可通过以下方式联系：

  • GitHub：github.com/heshengtao/super-agent-party
  • 电子邮件：可通过 GitHub Issues 索取

3. 我们收集的数据

我们不主动收集个人数据。我们的网站是纯静态网站，没有用户账户、无表单、无分析追踪器、无广告。但以下数据可能被自动处理：

  • 服务器日志（Cloudflare CDN）：本网站托管于 Cloudflare Pages。Cloudflare 会自动记录技术数据，例如您的 IP 地址、浏览器类型、引荐来源网址和访问时间戳。这些日志仅用于安全、性能和滥用防护目的。Cloudflare 作为我们的数据处理者。详情请参阅 Cloudflare 隐私政策。
  • 本地存储：我们将您的主题偏好（浅色/深色模式）存储在浏览器的 localStorage 中。此数据不会离开您的设备，我们也无法访问。
  • GitHub API（Star 数量）：网站显示我们开源项目的 GitHub Star 数量。这是从公开的 GitHub API 客户端加载的，由您的浏览器直接请求 GitHub，遵循 GitHub 的隐私政策。

4. Cookie 及类似技术

本网站不使用追踪类 Cookie。我们不设置任何用于分析、广告或用户追踪目的的 Cookie。我们仅使用 localStorage 记住您的主题偏好，这属于为您提供预期功能的严格必要项，依据 ePrivacy Directive 第 5(3) 条无需获得同意。Cloudflare CDN 可能设置用于机器人管理和安全的严格必要技术性 Cookie（如 __cf_bm）。

5. 处理目的与法律依据

任何个人数据（如服务器日志中的 IP 地址）的处理基于我们的合法利益（GDPR 第 6(1)(f) 条），具体包括：

  • 确保网站的安全性和稳定性
  • 防止滥用和网络攻击
  • 通过 CDN 高效地提供网站内容

6. 数据保留

Cloudflare CDN 日志的保留期限受 Cloudflare 的数据保留政策约束。我们无法访问原始服务器日志。localStorage 主题偏好存储在您的设备上，您可以随时通过浏览器设置清除。

7. 第三方服务

我们使用以下可能代表我们或独立处理数据的第三方服务：

  • Cloudflare（CDN 和托管）：处理 IP 地址和技术数据进行内容分发和安全保障。隐私政策
  • Google Fonts：我们从 Google Fonts CDN 加载字体。Google 可能会记录请求。隐私政策
  • Font Awesome：我们从 cdnjs Cloudflare CDN 加载图标资源。隐私政策
  • GitHub：GitHub Star 数量组件向 api.github.com 发起 API 请求。隐私政策
  • Tailwind CSS（CDN）：我们从 cdn.tailwindcss.com CDN 加载 Tailwind CSS。除标准 HTTP 请求外，不会向此 CDN 发送任何用户数据。

8. GDPR 赋予您的权利

如果您位于欧洲经济区（EEA），您根据 GDPR 享有以下权利：

  • 访问权（第 15 条）：请求确认我们是否处理您的个人数据，并访问该数据。
  • 更正权（第 16 条）：请求更正不准确的个人数据。
  • 删除权（第 17 条）：请求删除您的个人数据（"被遗忘权"）。
  • 限制处理权（第 18 条）：在特定情况下请求限制处理。
  • 数据可携权（第 20 条）：以结构化、机器可读的格式接收您的数据。
  • 反对权（第 21 条）：反对基于合法利益的处理。
  • 撤回同意权（第 7 条）：随时撤回同意（但我们不依赖同意进行处理）。
  • 投诉权（第 77 条）：向您所在的欧盟成员国的监管机构提出投诉。

由于我们不主动收集个人数据，上述大部分权利可以通过清除浏览器的 localStorage 或联系我们来实现。如有任何隐私相关疑问，请在我们的 GitHub 仓库 提交 Issue。

9. 儿童隐私

本网站不面向 16 岁以下的儿童。我们不会明知地收集儿童的个人数据。

10. 本政策的变更

我们可能会不时更新本隐私政策。变更内容将发布在此页面并更新"最后更新"日期。我们建议您定期查看此页面。

11. 联系方式

如对本隐私政策有任何疑问，请通过以下方式联系我们：

  • GitHub Issues：github.com/heshengtao/super-agent-party/issues
